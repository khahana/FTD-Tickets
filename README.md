# F-Trucks Deutschland — AfterSales Ticket System

**Proof of Concept Demo v1.0**

A standalone ticket management system for F-Trucks Deutschland GmbH's aftersales operations, built as a Progressive Web App (PWA).

## Quick Start

Open the live demo: **[https://khahana.github.io/ftd-tickets/](https://khahana.github.io/ftd-tickets/)**

Or download `index.html` and open it in any modern browser.

## Features

- 🎫 3 ticket categories with dynamic forms (Technisches, Ersatzteil, Sonstiges)
- 👥 9 F-Trucks team members with auto-assignment
- 🏢 73 sub-dealer partners
- 📊 16-section analytics dashboard with dealer drill-down
- 🌐 Bilingual UI (DE/EN) with DeepL translation mock
- 📱 PWA — installable on mobile devices
- 🌓 Dark/Light mode
- 📎 File attachments (PDF, JPEG, MP4)
